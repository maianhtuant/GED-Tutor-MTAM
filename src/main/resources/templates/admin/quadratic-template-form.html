💡 How the QUADRATIC generator works

For each question the generator picks random integers a, b, c in your ranges and computes the discriminant b² − 4ac.

  • Discriminant < 0 → No real solution (student types no real solution)
  • Discriminant = 0 → One repeated root (exact rational)
  • Discriminant > 0, perfect square → Two rational roots
  • Discriminant > 0, not perfect square → Two irrational roots (accepted within 0.5%)
