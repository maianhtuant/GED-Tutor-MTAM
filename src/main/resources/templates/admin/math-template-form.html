💡 Template syntax

Each unique {placeholder} gets one random integer in your range. The same placeholder reused multiple times always gets the same value.

Add :min-max inside the braces to give one placeholder its own range instead of using Min value / Max value — e.g. {a:1-50}.{b:1-100} draws a from 1–50 and b from 1–100 independently. Only the first occurrence of a name needs the suffix; reuse it bare afterward ({a}) and it'll still resolve to the same value.

{+-} is a special token that randomly shows + or − each time a problem is generated. It adds a sign variable s to the formula context: s = 1 for + and s = -1 for −. Use (c - s * b) / a so one formula covers both cases.

Functions — number theory: gcd() lcm() (1+ whole-number args); general math: min() max() (1+ args), abs() sqrt() floor() ceil() round() (1 arg), mod() pow() (2 args); trig: sin() cos() tan() (degrees), sinr() cosr() tanr() (radians); logs: log() (base 10) ln() (natural) exp() (e^x); combinatorics: fact() nCr() nPr(); statistics: mean() median() (1+ args). Results that aren't exact fractions (sqrt of a non-perfect-square, trig, log) are rounded to a high-precision approximation — plenty for grading tolerance/decimal places.

Comparisons & ternary — formulas can branch with > < >= <= == != and ? :, e.g. a > b ? a - b : b - a. Both branches are always evaluated (no short-circuiting), so avoid an untaken branch that divides by zero.
